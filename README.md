# 本命回响 · Agent Resonance

通过对局情境问答，找到你可能喜欢的无畏契约特工，并获得一份可以实际验证的试玩报告。

本版包含 16 道原创情境题、64 个选项、5 个玩法偏好维度和至多 3 名候选推荐。角色库覆盖当日全部 **30 名特工**。每名候选附有推荐依据、可能不适应的地方与试玩任务。现有界面、题库和推荐规则已沿用，运行方式适配为 **GitHub Pages 静态网站**。

**这是玩法偏好探索工具。结果不是科学人格测量、能力评估、竞技表现预测，也不是官方选角建议。**

在线体验：[本命回响 · Agent Resonance](https://zreh999.github.io/next-agent/)。已于 2026-11-11 完成 GitHub Pages 发布；发布者确认任务成功且公网首页正常打开。检查范围见 [验证记录](docs/verification.md)。

## 0.4：更像打瓦时会说的话

16 道题已改为购买阶段、进点、转点、双排和热身等具体场景。选项更短，开题前提供常见术语解释；不把枪法、段位或是否会开麦当人格判断。题库版本升为 `3.0.0`，计分表和角色推荐规则不变，旧报告仍保留原快照。社区阅读样本、心理学一手资料和逐题设计见 [题目改写研究](docs/question-design.md)。

结果页新增 1080 × 1440 艺术海报：首推立绘、候选副卡、角色主题色、五维刻度和经典短台词。30 名角色均有立绘映射和核对过的英文短句，中文为项目译意。外部图片不可用时仍可下载几何版本，并明确提示。当前采用图片与文字，不提供语音播放。来源与权利说明见 [媒体资料](docs/media-sources.md)。

## 产品流程

1. 在手机或电脑上完成情境问答，推荐在浏览器中即时计算。
2. 查看五维偏好可视化、至多三名候选特工及推荐解释。
3. 按任务尝试三局，将反馈保存在当前浏览器中。
4. 下载结果图片，按自己的意愿发送给朋友。

无需注册、数据库、Riot 账号、游戏战绩或 API key。题库与规则随静态网站一起分发；答案、报告和反馈不上传服务器或维护者，不会自动训练或改变推荐规则。

| 页面（相对于 `/next-agent/`） | 用途 |
| --- | --- |
| `agents/` | 搜索、按职责筛选完整 30 名特工 |
| `quiz/` | 完成问答，或通过 `?edit=报告ID` 修改本机回答 |
| `results/?id=报告ID` | 查看本机报告；不填 ID 时打开最近的本机报告 |
| `tryout/?id=报告ID` | 查看试玩任务并记录本机反馈 |
| `method/` | 了解规则、版本、数据保存方式和结果局限 |

## 数据保存与分享的变化

草稿、答案、报告及试玩反馈保存在当前网站来源下的浏览器本地存储中。刷新或重新打开同一浏览器可继续查看。清除网站数据、换设备、换浏览器、使用不同来源地址或关闭隐私浏览环境后，记录可能无法找回；网站不提供账号恢复、云端备份或跨设备同步。

报告链接只包含本地记录 ID。把它发给别人不会传输报告，对方没有你浏览器里的数据，不能仅凭该链接打开你的结果。分享请使用“下载分享卡”生成的图片。静态版没有服务器公开摘要，也没有原来的分享链接创建与撤销功能。

本地存储被禁用或空间不足时，页面会提示保存失败；不要把未成功保存的内容当作已经备份。试玩反馈仅用于个人回顾，维护者不会自动收到这些记录。

## 本地运行

使用 Node.js 24 及 npm：

```sh
npm ci
npm run dev
```

按终端提示访问网站。GitHub Pages 的子路径配置为 `/next-agent`，内部链接通过 Next.js 的 `basePath` 处理。正式构建与静态预览：

```sh
npm run build
npm run start
```

本地预览地址为 `http://127.0.0.1:3000/next-agent/`，构建产物位于 `out/`。当前版本不运行 Next.js 后端，也不需要 Prisma、PostgreSQL、Docker、`DATABASE_URL` 或 `APP_ORIGIN`。旧服务端实现可从 Git 历史查看。

## GitHub 上需要调整什么

1. 保留公开仓库 `zreh999/next-agent` 和 `main` 分支，把本次静态适配代码推送到该分支。
2. 打开仓库 **Settings → Pages → Build and deployment**，将 **Source** 设为 **GitHub Actions**。
3. 在 **Actions** 中确认 **Deploy to GitHub Pages** 工作流成功。后续向 `main` 推送代码会自动重新构建并发布。
4. 无需添加数据库连接、部署平台令牌或其他 Secrets，也无需注册 Vercel、Render 等托管账号。

构建目录由工作流上传，日常开发只需提交源码，不要把 `node_modules/`、`.next/`、`out/` 或 `.env` 上传到 Git。完整步骤及故障排查见 [部署文档](docs/deployment.md)。

## 技术与规则

项目使用 Next.js App Router 静态导出、React、Recharts、Zod、Vitest 和 Playwright。推荐采用版本化的加权 L1 距离规则，比较问答形成的偏好与特工玩法画像。匹配分只用于当前规则内的比较，不是适合该特工的概率，也不代表测量精度。

当前题库为 `3.0.0`、角色库为 `2.0.0`，算法规则另行版本化。报告保存生成时的三个内容版本及快照，更新不会自动改写旧结果。题目虽然参考心理学概念组织情境，但没有直接采用正式量表，也没有建立常模或信效度证据。详见 [方法说明](docs/methodology.md)、[问卷设计依据](docs/question-design.md)和 [内容维护指南](docs/content-guide.md)。
