# 问卷 3.0：像队友说话的 16 个对局选择

题库版本：`3.0.0`。公开资料检索与改写日期：2026-11-11。16 题、64 个原创选项；没有复制、翻译或改装正式心理量表题项。

这次改写解决的是可读性与游戏语境：让玩家知道“这题到底在问哪一种打法”，并愿意读完。它不把口语化当成心理测量效度，也不声称能测出稳定人格、枪法、意识、竞技潜力或胜率。

### 保留什么口语，去掉什么“黑话”

- 保留：这把、下把、进点、补枪、报点、双排、五排、架住、交技能、退路。它们都能指向一个具体动作或情境。
- 优先用中文：不要求懂 rush、eco、repeek、lurk、entry、contact 等缩写，也不要求知道某个职业绰号。
- 不把新手不懂词当成答题失败。可在开题前提供简短释义：补枪是紧跟队友接上交火，架枪是盯住一个方向，进点是进入包点，报点是告诉队友对面的位置或动静。
- 去掉原来反复出现的装背包、开始键、剧情反转、改写按钮、变拍、探险等意象。趣味来自熟悉的小尴尬和选择，而不是额外理解一层比喻。
- 不借用辱骂、摆烂、甩锅、炸鱼或性别梗制造笑点。轻松语气不应该暗示某种玩家更值得被推荐。

## 二、心理学知识怎样进入设计

### 自主、胜任与联结：问“想怎么玩”，而不是“应该怎么赢”

[Ryan 与 Deci（2000）的自我决定理论原文](https://selfdeterminationtheory.org/SDT/documents/2000_RyanDeci_SDT.pdf)讨论自主、胜任与联结等基本心理需要。[Ryan、Rigby 与 Przybylski（2006）的游戏动机原研究](https://selfdeterminationtheory.org/SDT/documents/2006_RyanRigbyPrzybylski_MandE.pdf)将这些概念用于研究游戏中的体验和继续游玩的动机。

本项目采用的设计启发是：自己找到机会、把一套操作练熟、和队友接上节奏，都可能让人愿意继续玩。所以 q11 问等待朋友时愿意怎么练，q13 问不看击杀数最想再体验哪一刻，q08、q15 问双排时想怎样协作。

这不等于三种需要就是三个职业，也不等于独立行动才自主、频繁开麦才有联结。论文没有提供本项目五轴的计分权重或特工映射。

### 机会与后手：两种取向都可以合理

[Higgins 实验室的研究说明与原始文献目录](https://www.columbia.edu/cu/psychology/higgins/research.html)介绍目标追求中的促进与预防取向；可追溯至 Higgins（1997），[Beyond Pleasure and Pain](https://doi.org/10.1037/0003-066X.52.12.1280)。

这里借用的是“争取机会”和“留意风险、准备后手”可以受到情境影响、并各有合理目的的视角。q01、q04、q06 没有将先动写成勇敢，也没有将等信号写成胆小；选择信息和准备的程度，也不等于判断能力高低。

本项目不测量正式的调节焦点，不把它简单换算成激进/保守，更不把某种取向直接等同于决斗、先锋、控场或哨卫。

### 这些仍是设计假设

五个玩法偏好轴、每个选项的整数分数、角色画像和推荐距离，均由维护者设计。它们不是论文估计出来的心理参数。保留相同的计分表，是为了控制这次文字适配的范围，不表示新题目自动继承了旧题目的测量质量。

多轴选项仍可能让玩家只喜欢一句话的某一半；相同玩家在熟人队、单排或不同地图中也可能选不同答案。结果适合当作试玩起点，不适合当能力评分或人格标签。

## 三、这 16 题怎么写得更自然

答题提示建议为：

> 选你更想体验的打法。假设时间、装备和队友条件允许这些选择，不用找最正确的战术答案；没遇到过的情况，就选你最愿意试的那种。

设计约束：

1. 一句话交代人在哪里、正在发生什么，再直接问你更想做什么。
2. 选项尽量一口气读完；本版最长选项为 25 个字符。四项都写行动或体验，避免只有一个像合格队友。
3. 信息少可以是已有线索够用，不写成闭眼乱冲；独立执行可以是分工后处理自己的路线，不写成不管团队。
4. 事先准备与临时换招可以同时较高。熟悉搭档的固定配合，也可以有较高协同、较低变化偏好。
5. 轻松来自门口集合却没启动、朋友排位前还要等十分钟、同一点打了三回合等具体体验；不要求每题塞一个梗。
6. 避免击杀数、段位、反应速度、记住技能数值或“队友太菜怎么办”，以减少把偏好题答成水平测验的诱因。
7. 选项顺序继续固定，尚未验证顺序效应；不同题的同一字母不代表同一种职业或统一高分。

## 六、版本与验证边界

`3.0.0` 修改了情境、提问、选项文本和维度显示文案；题号、选项 ID、每一项分数及规则算法均不变。这仍是题意变化，不能将 2.0 草稿默认为同一份作答。旧报告应继续展示创建时保存的快照，新报告记录 3.0.0 题库版本。

本次已检查 JSON 可解析、16 题、64 项、维度 ID、所有题号/选项 ID 及全部原分数一致。该检查不代替玩家可读性研究。新文字尚未做正式认知访谈、重测、因子分析、信效度或群体公平性检验。

下一步应先邀请不同经验的玩家解释“这题在问什么、我为什么选这一项”，重点找术语门槛、双重问题、明显讨好人的选项和理解后仍与计分方向不一致的答案；也可以观察完成率、改选和主观趣味反馈，但小样本不能推出心理学效度或推荐成功率。

玩家的真实试玩感受比一次自述更重要。题目更有趣不代表推荐更准确，也不提供诊断、能力评定或胜率承诺。
