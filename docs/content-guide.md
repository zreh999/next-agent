# 本命回响 · 内容与规则维护指南

## 定位与来源

本命回响（Agent Resonance，代码中也称 AgentResonance）是原创情境问答与玩法偏好推荐工具。题目、角色描述、推荐画像、负担等级和试玩任务由维护者设计，不是官方角色评分、正式心理量表或竞技能力测验。相同特工可以有多种打法；画像是一组可讨论、可修改的推荐假设。

当前角色库 `2.0.0` 按 **2026-11-11** 核对的 VALORANT 官方特工目录覆盖当日全部 **30 名特工**。这是有日期的覆盖快照，不是永久的“最新完整名单”声明。角色英文标识、职业与机制参考每条记录的 `sourceUrl`；单项资料的 `reviewedAt` 另行记录核对日期，不表示官方认可，也不表示对某个补丁的精确竞技评估。

## 文件职责

- `content/questionnaire.json`：题库 `2.0.0`，五个偏好维度、16 道原创情境题，每题四个选项，共64个选项。
- `content/agents.json`：角色库 `2.0.0`，30 名特工的五维画像、负担判断、取舍与试玩任务。四个职业都有覆盖，不要求各职业数量相等。
- `content/ruleset.json`：维度权重、负担罚项和候选选择容差；这些是独立版本化的维护者设计值。
- [`question-design.md`](question-design.md)：情境构造、概念参考与计分解释；不能用它替代心理测量验证。

## 题目合同

维度标识固定为 `initiative`、`intel`、`setup`、`adaptability`、`teamwork`。每题所有选项必须使用相同的分数键集合，分数为0—4的整数；同题选项的完整分数向量必须互不相同。题目可以只覆盖部分维度，不能把未覆盖维度当作零分。

每个维度至少由 **6道能实际区分答案的题目** 覆盖：同题四个选项都提供该维度分数，且至少两个选项分数不同。只有键存在、但所有选项得分相同的题，不能用来凑覆盖数量。具体题目与维度映射以当前问卷及设计说明为准，修改后运行内容审计测试。

编写时避免把特工名或职业直接放进答案，也避免把某个选项写得明显更勇敢、更聪明或更有团队精神。题目询问“更喜欢怎样参与”，不要求玩家证明自己知道唯一正确的战术。维度标签描述偏好，分数较高不代表更强。心理学概念可以启发情境与解释；原创题目不能继承正式量表的效度、常模或准确率。

`setup` 与 `adaptability` 可以同时较高：玩家可能既喜欢准备多个方案，也喜欢现场切换。不要把所有维度强行变成互斥类型，也不要把负担意愿、经验或开麦习惯当作固定人格。

## 角色目录审计

截至2026-11-11的30名角色标识快照为：

```text
astra breach brimstone chamber clove cypher deadlock fade gekko harbor
hush iso jett kayo killjoy miks neon omen phoenix raze reyna sage skye
sova tejo veto viper vyse waylay yoru
```

KAY/O的内部标识和官方页面slug可能采用 `kayo` / `kay-o` 的不同写法。以实际官方来源记录为准；审计会规范化连字符后逐一比对，不允许因此重复或漏掉角色。其他标识也必须与对应来源一致，不能只以总数30作为完整性的证明。

新增官方角色时，先核对名称、职业、来源与日期，再补全画像、取舍和三局任务。同步更新目录快照测试、覆盖日期、角色库版本及说明；旧报告保留原版本和快照。无需为了让角色数量看起来均衡而改变职业。

## 角色与试玩内容

每名角色必须有完整五维画像、1—3级练习和沟通负担、明确取舍，以及三条不同的试玩任务。画像范围是0—1。`practiceLoad` 和 `communicationLoad` 是维护者估计，不是适用于所有打法的官方难度结论。

将机制事实与推荐判断分开：官方资料用于核对机制；数值画像、适合的偏好和取舍由维护者解释并接受质疑。不要复制整段技能说明，也不要依赖容易随补丁变化的伤害等数值来给用户下结论。

试玩任务观察职责乐趣、管理负担和继续练习的意愿，不以胜负、击杀或段位作为唯一结论，不要求为完成任务而放弃队伍需要。优先选择普通对局中的小目标；陌生动作先在训练环境熟悉。

角色素材权利与代码许可证分别处理。引用官方页面不代表获得对全部Riot IP的再许可，也不代表产品通过Riot注册或审查。

## 修改、版本与验证

改变题目含义、选项计分、角色画像或规则参数时，更新对应文件的版本，并说明调整原因与影响范围。保存的报告快照绑定题库、角色资料与规则版本，避免更新后无声改变旧报告。

内容测试检查16题、64选项、五维有效覆盖、30名逐一名单、来源、画像范围和任务完整性。测试通过表示内容满足工程合同，不表示心理学测量有效或角色推荐已经被实证证实。

提出数值调整时，请给出具体场景、取舍以及修改前后样例。不要把个人熟练度、单局战绩或职业刻板印象当作唯一依据。体验反馈可以帮助人工审阅，但不能由少量反馈推出心理学效度或匹配成功概率。
